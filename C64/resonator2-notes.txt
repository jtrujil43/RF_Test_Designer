resonator2.bas - C64 BASIC V2 / MULTICOLOR BITMAP
================================================

Menus, input prompts, dimension tables, model notes and all strings use
standard 40x25 text mode. The three graphical viewer pages switch to
native 160x200 VIC-II multicolor bitmap mode. The five viewer pages remain:

1. Ring dimensions: text.
2. Top metal: text legend, then bitmap ring/feeds/ground banks/vias.
3. GSG launch: text dimensions and legend, then enlarged bitmap geometry.
4. Nominal modes: text frequencies, then bitmap frequency axis and ticks.
5. Assumptions/checks: text, including a second checks screen.

On pages 2-4, any key opens the bitmap after the text legend; M returns to
the menu. In the bitmap, any key advances and M returns to the menu. Both
paths restore standard text before any subsequent PRINT or INPUT. Text
pages use any key to advance. Input prompts retain Enter-for-default.

The bitmap palette is black background, yellow signal copper, cyan ground
banks and white via/contact/axis marks. The full layout plots the actual
circular or cosine-lobed polar ring shape, both coupling ports, filled
signal tapers, landing pads and ground banks. The launch detail enlarges
the GSG pads, taper, neck and probe contact centres. The mode plot shows
positions, not a transmission response. A zero-mode band shows an empty
axis and has no empty FOR-loop execution.

Bitmap pixels are twice as wide as they are high, so the layout uses
separate horizontal and vertical scales to keep a circle circular. Trace
widths and coupling gaps below display resolution receive minimum visible
pixels. These are schematic views, not manufacturing artwork; exact
physical dimensions remain in the text reports. Top-layout features use
one common physical scale except for minimum-size visibility adjustments.

The shared renderer is embedded as BASIC DATA plus a small machine-code
plotting helper. No cartridge, BASIC extension or external graphics file
is needed when loading the PRG. The renderer uses the high-memory VIC bank
so bitmap storage does not overlap the BASIC program or its variables.
Standard text mode is restored before each page header and menu.

Cardinal prober configuration - 2026-10-30
-----------------------------------------
The two-port ring retains two active GSG probes: P1 approaches from WEST
at negative X, and P2 approaches from EAST at positive X. NORTH and SOUTH
station probes are parked clear of this DUT. Each launch has its G-S-G
contacts along the local/global Y axis at -PP,0,+PP. Contact-centre X is
reported as +/-(X4+X5)/2 in millimetres. No two probes share one side.

The top-layout bitmap adds white inward approach arrows at the west/east
launches. Its text legend names the active probes and parked pair. The
launch-detail viewer identifies the west launch and mirrored east launch;
dimension reports and help repeat the same station convention. All
numerical geometry and the existing two coupling ports are retained.
The update does not add north/south feeds or a four-port ring solver.

Probe-body clearance, tip overtravel and substrate mounting remain
fixture-specific checks. The arrows indicate approach direction; they do
not prescribe a physical probe-body outline or guarantee mechanical fit.

The input flow, material presets, numerical models, fabrication checks,
50-ohm width synthesis, GCPW neck synthesis, 720-interval perimeter and
curvature integration, and unloaded resonance calculations are unchanged.
The guarded EXP calculations and thin-substrate GCPW asymptote remain.
The original parent-folder BASIC program was not modified.

Reproduce the full suite with:
  node verify_resonator.mjs C:\path\to\VICE\bin
RESONATOR_VICE_PORT selects a different unused monitor port.
RESONATOR_NUMERICAL_ONLY and RESONATOR_CASE select focused numeric checks.
The verifier refuses occupied ports and closes only the emulator it starts.
The screen transcript is saved in its temporary c64-bitmap-* directory.
