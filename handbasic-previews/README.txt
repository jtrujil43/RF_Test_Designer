HAND BASIC PREVIEW ATLAS

Open index.html for the gallery. The PDF report and its editable LaTeX
source are in ../reports. Full rebuild from the project folder:
  powershell -File reports/build.ps1

14 source-derived RF drawing views,2 literal utility text previews,
1 physical-stack/CPW-ground concept figure,and7 reference response plots.
SVG files are editable vector figures. PNG files are viewing images.
Command records and manifests identify the source lines and profile used.

Physical stack:2.2um Cu /6um LTC-25000 /700um EME-G730.
No continuous ground plane. Only top-side GSG grounds.
Probes:MPI TITAN67GHz,150um tip pitch. Range:0.5..67GHz.

IMPORTANT: The existing BASIC equations assume grounded structures.
Their numerical artwork labels and all response plots are hypothetical
grounded-polyimide references; they do NOT predict the actual stack.
er3.3 andtanDelta.01 are illustrative reference assumptions, not material
specifications. No EME-G730 dielectric constants are assigned.
These are host renders, not screenshots or execution tests of the mobile
Hand BASIC app, and the artwork is not a fabrication mask.

All10 parent-folder programs are included. C64-onlyRING67 is a separate
synthetic model and is not an additional Hand BASIC source program.
